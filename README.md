## A complete website structure

Depending on the project, an e-commerce system can include these pages and an administration area:

```text
website/
├── index.html       # Homepage and main value proposition
├── productos.html   # Product catalog
├── detalle.html     # Individual product details
├── nosotros.html    # About the business
├── contacto.html    # Contact information and conversion paths
└── admin/           # Administration area
```

The exact structure can change according to the project. The point is to build a connected website experience — not a single isolated page.
